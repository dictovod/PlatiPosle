# PlatiPosle

ПлатиПосле помогает пользоваться нейросетями и разбирать сайты. На сайте работают кабинет, чат и аудит. Помощник для Windows упрощает установку Cline.

**[Скачать PlatiPosle.exe для Windows x64](https://github.com/dictovod/PlatiPosle/releases/latest/download/PlatiPosle.exe)** · **[Открыть ПлатиПосле](https://platiposle.ru/)** · **[Личный кабинет](https://platiposle.ru/ai/cabinet/)**

## Помощник для Windows

**Версия 0.1.7** для Windows 10 и 11 x64.

1. Скачайте и откройте **PlatiPosle.exe**.
2. Вставьте API-ключ из личного кабинета и нажмите **Подключить**. Если нужен Node.js, Windows может запросить подтверждение его установки.
3. Когда откроется чат, напишите запрос и нажмите **Отправить**. Здесь же появится ответ. Действия Cline можно разрешить или отклонить.
4. Нажмите на голову робота, чтобы свернуть или снова открыть чат. Перетащите робота, чтобы переместить облако вместе с ним. Потяните за уголок вверху слева, чтобы изменить размер облака.

Cline работает в фоне, а задачи выполняются в папке `ClineProjects` в профиле пользователя. При первом запуске этой версии ключ нужно ввести один раз.

В чате можно написать «Сделай голову меньше», «Сделай голову синей», «Сделай облако #25283E» или «Верни оформление». Размеры и цвета сохраняются.

## Что доступно на сайте

| Возможность | Где открыть |
| --- | --- |
| Чат с диктовкой и поиском с источниками | [Чат](https://platiposle.ru/ai/cabinet/?chat=1) |
| Генерация и редактирование изображений | [Фото](https://platiposle.ru/ai/cabinet/?photo=1) |
| Анализ публичной страницы и план работ от ПлатиПосле | [Аудит](https://platiposle.ru/ai/cabinet/?audit=1) |
| Подключение своих инструментов к шлюзу | [Документация API](https://platiposle.ru/ai/) |
| Удалённая помощь с подтверждением сеанса | [Инструкция RustDesk](https://platiposle.ru/rustdesk/) |

Вход в кабинет доступен через Яндекс или Telegram. После покупки любого пакета токенов открываются дополнительные модели чата.
