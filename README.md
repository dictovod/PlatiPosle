# PlatiPosle

ПлатиПосле помогает пользоваться нейросетями и разбирать сайты. На сайте уже работают кабинет, чат и аудит. Отдельный помощник для Windows готовится к первому публичному выпуску.

**[Открыть ПлатиПосле](https://platiposle.ru/)** · **[Личный кабинет](https://platiposle.ru/ai/cabinet/)** · **[Сообщить о проблеме](https://github.com/dictovod/PlatiPosle/issues/new)**

## Что можно попробовать

| Возможность | Где открыть |
| --- | --- |
| Чат с нейросетью, диктовка и поиск с источниками | [Чат](https://platiposle.ru/ai/cabinet/?chat=1) |
| Генерация и редактирование изображений | [Фото](https://platiposle.ru/ai/cabinet/?photo=1) |
| Анализ публичной страницы и план работ от ПлатиПосле | [Аудит](https://platiposle.ru/ai/cabinet/?audit=1) |
| Подключение своих инструментов к шлюзу | [Модели и документация API](https://platiposle.ru/ai/) |

Войдите через Яндекс или Telegram в личном кабинете. После покупки любого пакета токенов в чате открываются дополнительные модели. Расход считается по тарифу выбранной модели.

## Помощник для Windows

**Статус — первая публичная сборка ещё не вышла.** Когда она появится, установщик PlatiPosle.exe будет доступен в [Releases](https://github.com/dictovod/PlatiPosle/releases).

Помощник рассчитан на Windows 10 и 11. Он открывает кабинет для получения API-ключа, помогает установить Cline и показывает ход настройки в плавающем окне.

После выхода сборки:

1. Скачайте PlatiPosle.exe из последнего релиза и запустите его.
2. Нажмите **Получить ключ**, если у вас его ещё нет, и откройте кабинет.
3. Вставьте ключ в окно помощника и нажмите **Установить Cline**. Windows может запросить подтверждение установки Node.js.
4. Когда настройка завершится, нажмите **Открыть Cline** или воспользуйтесь ярлыком PlatiPosle на рабочем столе.
