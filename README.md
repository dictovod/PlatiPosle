# PlatiPosle

Помощник для установки и настройки Cline на Windows 10 и 11. Он помогает открыть кабинет, ввести API-ключ и настроить подключение к шлюзу ПлатиПосле.

## Как установить после выхода сборки

1. Откройте [раздел Releases](https://github.com/dictovod/PlatiPosle/releases) и скачайте PlatiPosle.exe.
2. Запустите установщик и нажмите «Получить ключ», если ключа ещё нет.
3. Вставьте ключ из кабинета и нажмите «Установить Cline».
4. Дождитесь завершения и нажмите «Открыть Cline». После настройки его также можно открыть ярлыком PlatiPosle на рабочем столе.

Windows может запросить подтверждение при установке Node.js. API-ключ храните у себя и не размещайте его в обсуждениях.

Первая сборка с помощником пока готовится.
