# PlatiPosle

ПлатиПосле помогает пользоваться нейросетями и разбирать сайты. На сайте работают кабинет, чат и аудит. Помощник для Windows упрощает установку Cline.

**[Скачать PlatiPosle.exe для Windows x64](https://github.com/dictovod/PlatiPosle/raw/v0.1.0/PlatiPosle.exe)** · **[Открыть ПлатиПосле](https://platiposle.ru/)** · **[Личный кабинет](https://platiposle.ru/ai/cabinet/)**

## Помощник для Windows

**Версия 0.1.0**. Первая сборка помощника установки для Windows 10 и 11 x64.

1. Скачайте и откройте **PlatiPosle.exe**.
2. Нажмите **Получить ключ**, если ключа ещё нет, и откройте кабинет.
3. Вставьте ключ в окно помощника и нажмите **Установить Cline**. Windows может запросить подтверждение установки Node.js.
4. После настройки нажмите **Открыть Cline** или воспользуйтесь ярлыком PlatiPosle на рабочем столе.

Помощник настраивает подключение к шлюзу ПлатиПосле и GPT‑6 Luna. Кнопка с головой робота сворачивает окно. Для работы с задачами открывается штатный интерфейс Cline CLI.

Установщик не подписан. Контрольная сумма SHA-256:

```text
EC20E47EA43BE4FE636557F87FE88C8A8F90F6ABCECB2C6D6E391A36C585D578
```

## Что доступно на сайте

| Возможность | Где открыть |
| --- | --- |
| Чат с диктовкой и поиском с источниками | [Чат](https://platiposle.ru/ai/cabinet/?chat=1) |
| Генерация и редактирование изображений | [Фото](https://platiposle.ru/ai/cabinet/?photo=1) |
| Анализ публичной страницы и план работ от ПлатиПосле | [Аудит](https://platiposle.ru/ai/cabinet/?audit=1) |
| Подключение своих инструментов к шлюзу | [Документация API](https://platiposle.ru/ai/) |
| Удалённая помощь с подтверждением сеанса | [Инструкция RustDesk](https://platiposle.ru/rustdesk/) |

Вход в кабинет доступен через Яндекс или Telegram. После покупки любого пакета токенов открываются дополнительные модели чата.
